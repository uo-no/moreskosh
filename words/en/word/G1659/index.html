Senses (NGSD)

  1. to set free, to release (7)
    To set free, to release: “Christ has set us free”, “the truth will set you free”, “if the Son sets you free”, “having been set free from sin”, “freed from sin”, “has set you free”, “creation itself … will be set free”.
    Attested: NT · LXX · Fathers

    • John 8:32

      καὶ γνώσεσθε τὴν ἀλήθειαν, καὶ ἡ ἀλήθεια ἐλευθερώσει ὑμᾶς.

      You will know the truth, and the truth will make you free.”
