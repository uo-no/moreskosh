## 組版方式

データ → HTML → PDF。`scripts/build-ngsd-pdf-sample.cjs` が公開データから A4 用の HTML を組み、Playwright（Chromium）の `page.pdf()` で PDF に印刷する。手作業の調整はない。

```sh
node scripts/build-ngsd-pdf-sample.cjs --range "ROM 1:1" --out docs/samples/ngsd-pdf/rom-1-1 --date 2026-11-28
node scripts/build-ngsd-pdf-sample.cjs --range "ROM 1"   --out docs/samples/ngsd-pdf/rom-1   --date 2026-11-28
```

- 入力（読み取りのみ）：`public/assets/data/igsd/`（index.json・lemmas/・sense-map-gi.json）、`public/bible_data/nt/`、`public/books.json`、`proper-nouns/drafts/`（固有名詞の同定ドラフト）。
- 書体：Noto Serif CJK JP（和文）と Noto Serif（ギリシャ文字。和文の中のギリシャ文字も `unicode-range` で Noto Serif に回す）。どちらも SIL OFL 1.1 で、PDF に埋め込める。コンテナでは `apt-get install fonts-noto-cjk fonts-noto-core` で入れた。
- 体裁：A4、余白 16/14 mm。冒頭（範囲・収録語数・生成日・語義＝NGSD／編者 南田浩喜）→ 凡例（項目の構成・固有名詞の同定・根拠の説明）→ 2段組の項目 → 出典。柱（下）に書名・範囲とページ番号。
- 生成日以外は決定的（同じ入力から同じ HTML）。

項目は範囲内での初出順に並ぶ（ROM 1:1 は Παῦλος・δοῦλος・Χριστός・Ἰησοῦς・κλητός・ἀπόστολος・ἀφορίζω・εἰς・εὐαγγέλιον・θεός）。

## 項目の形（箇所中心形）

1. 見出し：原形・翻字・Strong 番号（NGSD が束ねる別番号があれば併記）・品詞（範囲内のトークンの `class`、ラベルはアプリの `app-shell.js` と同じ）・新約での総出現数（NGSD の `total`）。
2. 中心語義（`sense-map-gi` でその箇所に割り当てられた語義）：番号・ラベル・新約での件数・定義文・この箇所の用例（節番号と、語の前後5語のギリシャ語）。範囲内で複数の語義が使われていれば、それぞれをフルに載せる。
3. 他の語義：番号・ラベル・件数の一行。全文は語ページの URL へ案内。
4. 成句：NGSD の `idioms`（形・説明・新約の参照）。
5. この箇所の形：範囲内に出た形と形態（複数回は ×n）。

状態行と語義ごとの裏づけ行は項目に載せない。根拠の説明は凡例（冒頭の枠）に一度だけ載せている：収録した NGSD の見出し語はすべて新約の全用例に語義を割り当て済み（確定）であること、語義の根拠が「拡張照合」（新約の全用例から立て、LXX・教父の用例で裏づけを確認）と「拡張照合（新約のみ）」（LXX・教父に用例がなく、新約の用例のみに基づく）の二通りであること、語義ごとの裏づけは語ページにあること。文言は #406 の語ページと同じ。

### 固有名詞（NGSD に語義がない語）

語義の代わりに同定を載せる。`proper-nouns/drafts/<Strong>.json`（トークンの `lemmaId` `grc:G3972` → `G3972.json`）があれば、範囲内の各トークンの節（`BOOK 章:節`）を `identifications[].refs` に当てて、トークンが属する同定だけを載せる（範囲内にトークンのない同定は載せない）。

- 同定文（`label_ja`）は語義と同じ囲み（`.cs`／`.cl`）で示す。`roles` を持つ同定は、範囲内のトークンが属する役割を「役割」ラベルで、役割名・件数・参照（書名は `books.json` で日本語化）の順に示す。
- 表記（`variants.ja` の形）は「表記」ラベルで「、」でつなぐ。`sources`（確認元）は出さない。
- 同じ節が同一レンマの複数の同定に入っているとき（例：ヤコブ使徒1:13）は推測せず、該当する同定をすべて載せ、生成時に標準出力へ警告を出す。ローマ 1:1・1章では該当なし。
- ドラフトのない固有名詞は、見出し・この箇所の用例・この箇所の形だけで、断り書きは付けない。

ローマ 1:1 の Παῦλος・Χριστός・Ἰησοῦς はそれぞれ同定（パウロ／イエス・キリストと呼ばれる方／ナザレのイエス）と表記が出る。ローマ 1章で NGSD に語義がない 17 レンマのうち、ドラフトがあって同定が出たのは 5（Παῦλος・Χριστός・Ἰησοῦς・Δαυίδ・Ἕλλην）、残り 12（ὅς・ὁ・αὐτός・ἐγώ・σύ・Ῥώμη・τις・οὗτος・ἀλλήλων・ἑαυτοῦ・ὅστις・τοιοῦτος）は同定なし（固有名詞は Ῥώμη のみで、ドラフトはパイロット 33 レンマの外）。

LXX の用例は入れていない。lemma の `note`（LXX の箇所を含む）も載せていない。

## 中身の一致

語義・件数・定義・成句は、スクリプトが公開データをそのまま読んで出している（言い換え・補完なし）。ローマ 1:1 の中心語義は sense-map-gi のとおり：δοῦλος 1、κλητός 1、ἀπόστολος 1、ἀφορίζω 2、εἰς 6、εὐαγγέλιον 1、θεός 1。

## 判断が要る点（ユーザー確認事項）

1. **収録語数 242 と 230 の差**：仕様の「242」は lemmaId（Strong 番号）の異なり数。サンプルは「出現形はレンマに寄せる」に従ってレンマ単位にまとめたため 230 になった。差の内訳：NGSD 未収録の ἐγώ（4番号）・σύ（4番号）・ἑαυτοῦ（2番号）を各1項目に（−7）、NGSD が εἰμί の6番号（G1510・G1511・G1526・G2075・G2076・G5607）を見出し語 G2258 に束ねている分（−5）。なお πρῶτον（G4412）は NGSD の割り当てに従い πρῶτος（G4413）の項目に入る（件数は変わらない）。
2. **拡張照合の区別は項目では示さない**：#414 の仕様で状態行を除いたため、どの語が拡張照合か（新約のみか）は項目からは分からず、凡例の説明だけになる。collation のない語（482語）の根拠も、公開データに記述がないため載せていない。
3. **見出しの総出現数**：NGSD 収録語は NGSD の割り当て総数（`total`）。束ねた見出し語（例：εἰμί）は束ねた全番号の合計になる。
