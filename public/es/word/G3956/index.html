πᾶς pas G3956

Glosa

todo; cada

Apariciones en el Nuevo Testamento

1,246

Acepciones (IGSD)

  1. cada / todo (1,100)
    El todo que se extiende a cada miembro. «Todas las personas», «toda enfermedad», «en todo aspecto». Con una negación, «ninguno».
  2. todo (totalidad) (49)
    «Todo» referido a las cosas como un conjunto único.
  3. cualquiera / cualquier cosa (57)
    Se refiere a uno cualquiera. «Cualquiera», «cualquier cosa», «por cualquier razón».
  4. máximo / de todo corazón (28)
    Expresa plenitud de grado. «Toda-», «de todo corazón».
  5. siempre / continuamente (11)
    En la forma διὰ παντός, expresa continuidad del tiempo.
