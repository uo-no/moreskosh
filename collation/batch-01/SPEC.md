# NGSD 拡張照合 バッチ1（頻度6〜25回帯・下書き）仕様

## サイズ規則（最優先）
- 作業単位は **1レンマ**。返信は1レンマ分だけにし、15レンマをまとめて返さない。
- 返信は **下記の JSON だけ**（説明文・入力データの繰り返し禁止）。要約も付けない。
- 返信が途中で切れたら、最後に完了したレンマを名指しして「続き」だけを再開する。完了分は再送しない。

## モデル指定
Sonnet（下書き専用。確定ではない）

## 対象（15レンマ、パケットは同フォルダの G*.json）
G1186 δένδρον, G2753 κελεύω, G3022 λευκός, G3379 μήποτε, G3129 μανθάνω,
G3918 πάρειμι, G4202 πορνεία, G4674 σός, G5368 φιλέω, G79 ἀδελφή,
G93 ἀδικία, G308 ἀναβλέπω, G337 ἀναιρέω, G1859 ἑορτή, G2641 καταλείπω

## 材料（パケットの読み方）
- `nt_occurrences`：新約の全用例（箇所・語形・形態・英日グロス・節文）。**語義の対象はこの用例だけ**。
- `lxx` / `fathers`：拡張母集団の総件数・書別内訳・代表例。語義の裏づけ（照合）に使う。
- `abbott_hypothesis_en`：Abbott-Smith の記述。**仮説として扱い、文言を写さない**。用例と合わない場合は用例を優先し、その旨を unresolved ではなく note に残す。

## 出力形式（1レンマにつき1つの JSON）
```json
{
  "strong": "G93", "lemma": "ἀδικία",
  "senses": [
    {"n": 1, "label_ja": "（訳語候補）", "def_ja": "（語の本質的な意味を記述した定義文）",
     "layers": {"nt": 25, "lxx": "attested|none", "fathers": "attested|none"},
     "note": "（任意：構文情報・層での違い等）"}
  ],
  "assignments": {"MAT 1:1": 1},
  "unresolved": [{"ref": "ROM 1:1", "reason": "（判断が割れる理由）"}],
  "layer_notes": "（任意：LXX・教父にだけ現れる用法があればここに記録。語義にはしない）"
}
```

## 規則
1. 語義は新約の用例から立てる。LXX・教父の用例は裏づけ専用で、新約に無い用法は語義にせず `layer_notes` に記録する。
2. 新約の全用例を必ずどれかの語義に割り当てる。割れないものは無理に寄せず `unresolved` に理由つきで残す。
3. `label_ja` は訳語候補、`def_ja` は本質定義の二層に分ける（既存 NGSD の体裁に合わせる）。
4. 各語義に層別の有無（layers）を必ず付ける。代表例で確認できない層は "none" と書く（総件数だけで "attested" にしない。代表例の範囲で確認できた場合のみ）。
5. 状態は「拡張照合」の下書き。final と書かない。
6. 固有名詞は対象外（このバッチには含まれていない）。
